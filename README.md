# Umair Khan — AI Engineer Portfolio

> Ultra-modern 3D portfolio built with React, Vite & Three.js

## 🚀 How to Run

**Double-click `start-portfolio.bat`** — starts the server and opens the browser automatically.

Or manually:

```powershell
npm run dev
```

Then open **http://localhost:5173/**

## 🛠️ Tech Stack

- **React 19** + **Vite 8**
- **Three.js** — interactive neural network background
- **Inter** + **JetBrains Mono** — typography
- Vanilla CSS — glassmorphism, animations, design system

## 📁 Structure

```
src/
├── App.jsx          # All portfolio sections
├── App.css          # Component styles
├── index.css        # Design system / global styles
├── NeuralCanvas.jsx # Three.js 3D background
├── hooks.js         # Scroll-reveal, typewriter, nav hooks
└── main.jsx         # Entry point
```
